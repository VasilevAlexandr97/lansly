# Lansly

🤖 Бот: [@lansly_bot](https://t.me/lansly_bot) · 🌐 Сайт: [lansly.ru](https://lansly.ru)

Lansly — сервис, который отслеживает новые проекты на фриланс-биржах Kwork и FL.ru и доставляет подходящие заказы прямо в Telegram. Сервис отфильтровывает проекты по выбранным категориям, цене и нежелательным словам, оставляя только релевантные. Для понравившихся заказов Lansly автоматически готовит отклик с помощью ИИ на основе профиля фрилансера и текста задания.

## Отслеживаемые источники

| Название источника | Ссылка на источник |
| --- | --- |
| Kwork | [kwork.ru](https://kwork.ru) |
| FL.ru | [fl.ru](https://fl.ru) |

## Функционал

**📡 Отслеживание заказов**

- Мониторинг новых проектов на Kwork и FL.ru каждую минуту и отправка уведомлений в Telegram
- 🗂 Выбор источника и подписка на интересующие категории и подкатегории проектов по дереву категорий выбранной биржи
- 💰 Фильтрация заказов по диапазону цены (минимум/максимум)
- 🧹 Исключение заказов по стоп-словам — проекты, содержащие нежелательные слова, не приходят

**🤖 Отклики с помощью ИИ**

- Автоматическая генерация отклика на проект на основе текста заказа и профиля фрилансера
- 👤 Личный профиль фрилансера (опыт, навыки, специализация), которым ИИ руководствуется при составлении откликов
- ✏️ Управление профилем прямо в боте

## CLI-команды

| Команда | Описание |
| --- | --- |
| `import-categories` | Импортирует деревья категорий и подкатегорий с Kwork и FL.ru в базу данных |
| `create-admin --username <логин> --password <пароль>` | Создаёт администратора для входа в админ-панель |
| `recalc-daily-metrics` | Пересчитывает все дневные метрики с нуля |
| `weekly-report` | Собирает недельный отчёт за две последние полные недели и выводит его в лог |

Запуск (требует рабочего окружения: Postgres, Redis и заполненного `.env`):

```bash
uv run lansly import-categories
uv run lansly create-admin --username admin --password secret
uv run lansly recalc-daily-metrics
uv run lansly weekly-report
```
